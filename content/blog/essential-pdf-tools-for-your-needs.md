The right PDF workflow depends on whether you want to create a document, read it, extract tables, or reduce its size. These are different tasks, and the quality of the source file matters.

Here is how to choose among the document tools currently available on MyConverterTool.

## Convert a document to PDF

Use the [PDF Converter](/tools/pdf-converter?mode=convert) for supported Word, Excel, PowerPoint, Markdown, text, and image files.

1. Choose the file conversion action.
2. Upload your source file.
3. Start the conversion and wait for processing to finish.
4. Preview the PDF and check the layout before downloading it.

Pay particular attention to page breaks, wide tables, substituted fonts, and images. A successful conversion means a file was generated; it does not replace reviewing the result.

## Open a PDF without editing it

Choose [View a PDF](/tools/pdf-converter?mode=view) when you only want to read a document in the online viewer.

The viewer is not a full PDF editor. It does not provide a way to rewrite existing page text or redesign the original document. Make those changes in the source application when possible, then export a fresh PDF.

## Move tables between PDF and Excel

The [Excel and PDF converter](/tools/excel-pdf) has separate directions:

| Direction | Typical use | Main check |
| --- | --- | --- |
| Excel to PDF | Share a spreadsheet as a document | Paper size, orientation, and width |
| PDF to Excel | Reuse tables from a text-based PDF | Columns, headers, merged cells, and numbers |

For PDF extraction, try the available table detection options when the first result is incomplete. A table can look clear to a person while its underlying PDF text is positioned in an unexpected order.

Scanned pages are a separate challenge. If a PDF contains only photographed text, table extraction may not produce usable cells. Do not assume the tool includes OCR for every uploaded document.

## Reduce size with a quality check

Use [Compress PDF](/tools/file-compressor?mode=pdf) when a document is too large to share. Start with the recommended setting, then compare the download with the original.

Check small print, diagrams, and image detail. Already optimized PDFs may have little room for further reduction. Keep the original whenever document quality matters.
