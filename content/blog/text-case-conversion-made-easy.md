Inconsistent capitalization can make a document harder to scan. A text case converter helps you change presentation quickly, especially when you are cleaning headings, imported lists, or notes copied from another application.

Start with the [Text Case Converter](/tools/text-case-converter), then review names and abbreviations before reusing the output.

## Pick the case that matches the job

| Option | Example | Common use |
| --- | --- | --- |
| Uppercase | `PROJECT NOTES` | Short labels or identifiers |
| Lowercase | `project notes` | Normalizing a sample or checking a match |
| Title case | `Project Notes` | Headings that need capitalized words |
| Sentence case | `Project notes` | Turning a heading into sentence-style text |

These are text transformations, not a complete editorial style guide. A capitalization rule cannot always identify a person's name, a product, or a technical abbreviation correctly.

## Convert a small sample first

1. Paste the text into the working area.
2. Choose the required case.
3. Read the converted result.
4. Copy or download it when it matches your needs.

For example, changing `MONTHLY SALES REPORT` to sentence case can make a heading less visually aggressive. However, changing `API URL CHECK` may require a manual correction so that `API` and `URL` keep their intended capitalization.

## Preserve meaning while editing

Take care with words whose case carries meaning. Product names, initials, code identifiers, and file paths should not be changed casually.

Keep code and ordinary prose separate. Turning a paragraph into lowercase is usually a presentation choice; turning a case-sensitive path into lowercase can point to a different resource.

The tool also cannot decide which heading style your organization requires. Use the output as a starting point, then apply the appropriate style consistently across the document.

## Finish with a quick review

Read the first sentence, check proper nouns, and scan any abbreviations. If the text will be published, verify spelling and punctuation as well as case.
